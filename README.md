# سامانه هوشمند مدیریت ساختمان و مجتمع‌های مسکونی (Aparteman)

سامانه جامع مدیریت هوشمند ساختمان، واحدها، صدور شارژ و تسهیم هزینه‌ها با الهام از سامانه آپارتمانا.

---

## 🏗 معماری پروژه (Monorepo)

پروژه به صورت دو بخش کاملاً مجزا و استاندارد تفکیک شده است:

```
aparteman/
├── backend/    # لاراول ۱۱ ماژولار (Laravel Modular Monolith API)
│   ├── app/
│   ├── config/
│   ├── database/
│   ├── Modules/
│   │   ├── Auth/         # لاگین OTP / پسورد و سوئیچ نقش‌ها
│   │   ├── Building/     # مدیریت مشخصات ساختمان و بلوک‌ها
│   │   ├── Unit/         # مدیریت واحدها و انتساب ساکن/مالک + ایمپورت اکسل
│   │   ├── Billing/      # صدور قبوض شارژ با ۱۰ فرمول تسهیم و جریمه دیرکرد
│   │   ├── Expense/      # هزینه‌ها، کنتورخوانی (آب/برق/گاز) و روش‌های تسویه
│   │   └── Accounting/   # صندوق ساختمان و گردش مالی
│   └── composer.json
│
└── frontend/   # فرانت‌اند مدرن Next.js 15 + Tailwind CSS + Shadcn UI
    ├── src/
    │   ├── app/          # App Router و صفحات سامانه
    │   ├── components/   # کامپوننت‌های داشبورد، ثبت ساختمان، ویزارد شارژ و پورتال ساکنین
    │   └── lib/          # استور مرکزی و توابع کمکی
    └── package.json
```

---

## 🚀 راهنمای سریع اجرا

### ۱. اجرای بخش بک‌اند (Backend - Laravel):
```bash
cd backend
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```

### ۲. اجرای بخش فرانت‌اند (Frontend - Next.js):
```bash
cd frontend
npm install
npm run dev
```

## 🌟 قابلیت‌های پیاده‌سازی شده:
1. **احراز هویت و دسترسی‌ها:**
   - ورود با شماره موبایل و کد یکبار مصرف (OTP) یا رمز عبور.
   - تفکیک نقش‌ها در سطح هر ساختمان با استفاده از قابلیت Teams در **Laratrust**.
   - پشتیبانی از حالت‌های: مدیر ساختمان، مالک و ساکن، مستاجر، و کاربر بدون نقش (هدایت به ثبت ساختمان جدید).
2. **مدیریت واحدها:**
   - ثبت تکی و گروهی (اکسل) واحدها همراه با ایجاد خودکار حساب کاربری برای ساکنین و مالکین با رمز پیش‌فرض کدملی.
3. **موتور صدور شارژ و تسهیم (Billing Engine):**
   - محاسبه بر اساس متراژ، نفرات، شارژ پیش‌فرض، مبلغ ثابت و ترکیبی.
   - جریمه دیرکرد روزانه و پیش‌نمایش زنده مبالغ قبل از صدور نهایی.
4. **هزینه‌ها و کنتورخوانی:**
   - ثبت ارقام کنتور آب، برق و گاز و تسهیم به نسبت مصرف.
   - امکان تسویه به دو شیوه: اعلام به اهالی (کسر از صندوق و بدهکار شدن واحدها) یا پرداخت مستقیم از صندوق بدون اعلام.
