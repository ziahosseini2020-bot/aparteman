# سامانه هوشمند مدیریت ساختمان (Aparteman App)

این پروژه پروتوتایپ کامل و مدرن سامانه مدیریت ساختمان، واحدها، صدور شارژ و حسابداری آپارتمان است که با **Next.js 15** و **Tailwind CSS** طراحی شده است.

## امکانات پیاده‌سازی شده:
1. **احراز هویت و مدیریت نقش‌ها:**
   - ورود با رمز یکبار مصرف پیامکی (OTP) یا رمز عبور
   - سوئیچ نقش بین مدیر ساختمان، مالک و ساکن، مستاجر، و کاربر بدون نقش
   - فرم تعریف ساختمان جدید با اطلاعات مکانی و بانکی و بلوک‌بندی چندگانه
2. **مدیریت واحدها:**
   - ثبت تکی واحد با تفکیک مالک و مستاجر
   - ورود دسته‌جمعی از فایل اکسل (Excel) همراه با پیش‌نمایش جدول داده‌ها
3. **موتور صدور شارژ (Billing Engine):**
   - فرمول‌های تسهیمی: ثابت، شارژ پیش‌فرض، متراژ، نفرات، و ترکیبی
   - جریمه دیرکرد روزانه و پیش‌نمایش زنده محاسبات
4. **هزینه‌ها و کنتورخوانی:**
   - ثبت ارقام کنتور آب، برق و گاز و تسهیم به نسبت مصرف
   - هزینه‌های عمومی با انتخاب روش تسویه (اعلام به اهالی با بدهکار شدن واحدها یا پرداخت مستقیم از صندوق)
5. **پورتال ساکنین:**
   - مشاهده قبوض و بدهی‌ها و شبیه‌ساز پرداخت آنلاین شتاب با صدور رسید الکترونیکی

## نحوه اجرا:
```bash
npm install
npm run dev
# یا برای اجرای پروداکشن:
npm run build
npm start
```
